# Instructions

Clone this repository https://github.com/mosaic-avantos/frontendchallengeserver and follow its readme's directions. 

Once the frontend challenge server is running, open a new terminal or tab in your terminal, then clone this repository using https://github.com/arthmis/avan-th.git

`cd` into avan-th and run `npm install`. Once that is finished you can run the app with `npm run dev`.

Go to the link displayed by the command, most likely http://localhost:5173/, and from there everything should work. You should see a list of forms. You can click on the names of the forms to see its field and then select or deselect sources used for the forms.
